# CNC 外贸学习站

面向外贸 SOHO 与新手的 CNC 加工知识教程——从看懂图纸到收妥尾款，一本完整的中文在线教科书。

**在线阅读**：本地运行见下方「本地预览」，或部署到任意静态托管后访问。

## 课程策划

**目标读者**：零基础 CNC 外贸 SOHO、有客户但缺产品知识的外贸业务员、采购/跟单新手、想转外贸的工厂业务员。

**教育目标**：学完本课程，学员能独立完成 CNC 定制件外贸的完整闭环——

> 看懂图纸 → 听懂工艺 → 看见市场 → 找到客户 → 报出价格 → 兜住售后

**章节架构**（六篇十五章＋绪论＋英语分册＋附录）：

| 篇 | 章 | 覆盖能力 |
|---|---|---|
| 绪论 | 三个最常见的坑（薄壁/公差/刀纹） | 建立行业直觉 |
| 一 · 认识行业 | 1 认识 CNC 加工；2 外贸服务商的角色 | 看懂行业与自己的位置 |
| 二 · 读懂产品 | 3 材料入门；4 工艺与表面处理；5 读懂工程图纸 | 听懂产品语言 |
| 三 · 看见市场 | 6 买家地图；7 市场与证据 | 定位客户与市场 |
| 四 · 找到客户 | 8 获客渠道；9 询盘处理（要素清单＋英语十句） | 打开对话 |
| 五 · 报价与成交 | 10 成本与报价；11 条款与物流；12 谈判与下单 | 报价与成交 |
| 六 · 交付与售后 | 13 打样与量产；14 品质与验收；15 售后与复购 | 交付与长期经营 |
| 外贸英语分册 | 场景 1-6（询盘/报价议价/订单跟进/客诉/付款催款/礼貌维护） | 商务英语工具箱 |
| 附录 | A 术语表；B 邮件模板库；C 图纸符号速查；D 检查清单集 | 随用随查 |

## 学习线路

同一本教科书，四条走法（详见首页）：

1. **🚀 最小可用线**：绪论 → 第 5 → 9 → 10 章（最快处理第一个真实询盘）；
2. **📚 完整教科书线**：绪论 → 第 1 章按序到第 15 章（零基础推荐）；
3. **💼 业务员速成线**：第 5 → 9 → 10 → 11 → 12 → 14 章；
4. **🏭 工厂转外贸线**：第 2 → 6 → 7 → 8 → 11 章；
5. **🗣️ 英语并行线**：英语分册场景 1 → 6，随主线边用边学。

每章末尾有自测——过关才进下一章。

## 设计说明

- **体例**：每章固定骨架——场景导入 → 知识拆解 → 清单/表格 → 自测 → 术语卡 → 「接下来学什么」页尾衔接；
- **写作原则**：第二人称面向读者；通用场景举例（不含真实人物与公司）；重要概念配白话类比；利弊两面讲；
- **视觉**：编辑风——白头部、蓝链接、墨色大标题、柔和提示块、紧凑表格（样式见 `docs/stylesheets/custom.css`）；
- **技术栈**：[Zensical](https://zensical.org)（Material for MkDocs 的官方继任，Rust 实现）＋ Markdown 手写内容，零构建依赖之外无任何订阅服务。

## 本地预览

需要 Python 3 与 [uv](https://docs.astral.sh/uv/)：

```bash
uv run --with zensical zensical serve
```

打开终端提示的地址（默认 http://127.0.0.1:8000），改 Markdown 实时热载。

## 构建与部署

```bash
uv run --with zensical zensical build   # 产出纯静态文件到 site/
```

`site/` 目录是纯静态 HTML，可部署到任意静态托管：

- **Cloudflare Pages**：构建命令 `uv run --with zensical zensical build`，输出目录 `site`；
- **GitHub Pages / Netlify / Vercel**：同样指向 `site` 目录即可。

## 目录结构

```
├── mkdocs.yml          # 站点配置（导航/主题/扩展）
├── docs/
│   ├── index.md        # 首页：教科书目录＋学习线路
│   ├── lessons/        # 全部章节（绪论/ch01-15/en01-06/附录 A-D）
│   └── stylesheets/    # 自定义样式
└── site/               # 构建产物（不入库）
```
