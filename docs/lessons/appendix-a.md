# 附录 A · 中英术语表

按主题分组的 CNC 外贸常用术语。学习各课时遇到生词回这里查；建议配合各课自测使用。

## 图纸与公差

| 英文 | 中文 | 备注 |
|---|---|---|
| drawing | 图纸 | revision＝图纸版本（rev A/B） |
| tolerance | 公差 | ±0.05/±0.02 |
| GD&T | 几何尺寸与公差标注 | 机械图纸的标注语言体系 |
| flatness | 平面度 | 面平不平 |
| callout | 图纸标注 | callout on drawing |
| Ra (surface roughness) | 表面粗糙度 | 数值越小越光 |
| Ø / R | 直径 / 圆角半径 | 图纸常见符号 |

## 工艺

| 英文 | 中文 | 备注 |
|---|---|---|
| milling / turning | 铣削 / 车削 | CNC 两大主流工艺 |
| drilling / reaming | 钻孔 / 铰孔 | 铰孔用于修正孔径 |
| peck drilling | 啄钻 | 深孔钻一点退一点排屑，防断刀 |
| tapping | 攻丝 | 加工内螺纹 |
| blind hole / through hole | 盲孔 / 通孔 | THR＝通孔标注 |
| finishing pass | 精加工走刀 | 最后一刀决定光洁度 |
| stepover | 刀路间距 | 间距大＝纹粗 |
| tool marks | 刀纹 | 机加黑话 |
| DFM (Design for Manufacturing) | 可制造性反馈 | 工厂工程对图纸的工艺建议 |
| CMM | 三坐标测量机 | 高精度尺寸检测设备 |

## 材料与表面处理

| 英文 | 中文 | 备注 |
|---|---|---|
| 6061-T6 / 7075 | 常用铝合金牌号 | T6＝热处理时效状态 |
| anodizing | 阳极氧化 | Type II 普通／Type III 硬质 |
| bead blast / sandblasting | 喷砂 | 可掩盖细刀纹 |
| laser engraving | 镭雕 | 激光刻 logo/标识 |
| surface finish | 表面光洁度 | ⚠️ 歧义词，也可指表面处理 |

## 贸易与物流

| 英文 | 中文 | 备注 |
|---|---|---|
| RFQ | 询价单 | Request for Quotation |
| inquiry | 询盘 | 客户的购买询问 |
| quotation / quote | 报价 | — |
| PI (Proforma Invoice) | 形式发票 | 下单依据 |
| MOQ | 最小起订量 | Minimum Order Quantity |
| DAP / DDU / DDP | 贸易术语 | 运费与关税谁担的三种约定 |
| lead time | 交期 | 从下单到出货的时间 |
| approved sample | 签样 | 纠纷裁定基准 |
| AQL | 抽样验收标准 | Acceptable Quality Level |

## 品质与售后

| 英文 | 中文 | 备注 |
|---|---|---|
| meet spec / out of spec | 达标 / 超差 | 客诉高频 |
| rework / scrap | 返工 / 报废 | 处理不合格品的两条路 |
| sealing surface / mating surface | 密封面 / 贴合面 | 功能性表面 |
| cosmetic | 外观的 | cosmetic part＝外观件 |
| assembly | 装配/总成 | in your assembly 你装配件里 |
| corrective action/plan | 纠正措施/方案 | 客诉回复必用 |
| findings | 核查结果 | findings and corrective plan 常配对 |
| concession | 让步接收 | 客户书面同意「这个状态能收」 |
