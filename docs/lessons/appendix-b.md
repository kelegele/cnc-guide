## 通用写作原则

1. **一封邮件一个动作**：结尾只给一个明确的下一步；
2. **不过度承诺**：时限、价格、性能，写之前想清楚能不能兑现；
3. **坏消息三要素**：原因一句＋新日期＋补救方案；
4. **降价必有交换**：任何让步都换回一个条件（数量/交期/条款）。

!!! tip "沉淀你自己的模板"
    每封真实往来邮件都是模板的种子：好用的句式抄进你的句式本，按场景归类——三个月后你就有一本独家手册。
