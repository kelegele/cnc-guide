# 附录 C · 图纸符号速查

零基础阶段只要求：**认出「哪里有特殊要求」，原样抄下来问工厂工程师**——抄错不会，看漏才会。

## 最常见 6 个符号

| 标注 | 意思 |
|---|---|
| Ø | 直径 |
| R | 圆角半径 |
| Ra 1.6 / 3.2 | 表面粗糙度（数值越小越光） |
| THR / Through | 通孔（打穿的孔） |
| TAP M3 | 攻 3mm 公制螺纹孔 |
| 平面度框格（⏥＋数值） | 整面平直要求——密封面的常见信号 |

## GD&T 常用框格（进阶预告）

| 符号 | 名称 | 白话 |
|---|---|---|
| ⏥ | 平面度 | 整个面离「绝对平」的最大偏差 |
| ⊥ | 垂直度 | 两个面之间必须垂直的程度 |
| ⌖ | 位置度 | 孔或特征的位置允许偏移多少 |
| ◎ | 同轴度 | 两段回转特征是否同心 |

完整的 GD&T 体系讲解见[第 5 章 · 读懂工程图纸](ch05.md)。
