# 附录 D · 检查清单集

全站检查清单汇总，按业务流程排序——用一单查一单，避免 90% 的扯皮与返工。

## 1 · 报价要素 10 项（拿到图纸时）

材料＋状态｜数量分档｜外形尺寸｜关键公差｜壁厚｜深孔/深腔｜螺纹｜表面处理｜检测要求｜包装运输——逐项详解见 [9.1](l1-01.md)。

## 2 · 接单三问快筛（判断能不能接）

- [ ] 最薄壁厚 < 1.5mm？（薄壁易变形报废）
- [ ] 关键公差 < ±0.05mm？（进精密档，成本跳档）
- [ ] 验收需要 CMM 全尺寸？（确认工厂检测能力）
- [ ] 命中任何一条 → DFM 让工厂工程出、报价先问厂

## 3 · 询价口径归一清单（向工厂询价时）

- [ ] 同一张图纸/示意图发多家
- [ ] 材料与状态写明（6061-T6）
- [ ] 数量档位写明（5/50/500）
- [ ] 追问三件：含税吗？含表面处理吗？按什么数量档？
- [ ] 报价入台账（工厂/日期/口径/价格）

## 4 · 下单前确认清单（开工前）

- [ ] 图纸版本号确认（per Rev X）
- [ ] 材料与状态
- [ ] 表面处理（颜色/类型/遮蔽要求；染色件签色板）
- [ ] 关键公差与验收基准（签样 or 图纸公差）
- [ ] 数量与分档
- [ ] 贸易条款、运费与目的地邮编（偏远核查）
- [ ] 交期（工作日口径＋缓冲）
- [ ] 付款条款与定金到账

## 5 · 出货前验收清单（出货前）

- [ ] 关键尺寸抽检/全检，对照图纸公差
- [ ] 外观检查（氧化色、表面、磕碰伤）
- [ ] 对照签样（如有）
- [ ] 包装确认（单件保护＋外箱）
- [ ] 拍照留档（出货状态证据）

## 6 · 客诉处理四步（收到投诉时）

- [ ] 受理：快速回应（收到/重视/在查）
- [ ] 调查：图纸＋签样＋检测报告比对
- [ ] 方案：返工/重做/让步接收，给客户选项
- [ ] 复盘：问题归档 → 检查清单新增一条

!!! tip "让清单长大"
    每次踩坑后，把「这次漏了什么」变成清单里的一行——这份清单就是你的经验库，也是最难被抄走的资产。
