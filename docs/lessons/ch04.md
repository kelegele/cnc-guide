# 第 4 章 工艺与表面处理

!!! note "本章解决什么问题"
    工厂说「这个做不了」「这个要加价」时，你听得懂原因吗？这一章讲 CNC 的能力边界（精度、薄壁、深孔、深腔）与表面处理族谱——绪论里埋的那些坑，在这一章彻底填平。

## 精度阶梯：公差与成本的关系

| 精度档 | 典型公差 | 加工方式 | 成本含义 |
|---|---|---|---|
| 常规 | ±0.1mm 级 | 普通加工顺手可达 | 基准 |
| 标准精密 | ±0.05mm | 普通精铣，多数厂常规口径 | 行业默认报价档 |
| 高精密 | ±0.02mm | 慢走刀＋全检 | 加价明显（跳档） |
| 超精密 | ±0.01mm 及以上 | 磨床等精加工工艺 | 接近翻倍 |

记忆要点：**公差-成本曲线是非线性的**，档位之间是「跳」不是「匀速涨」；给客户的每个精度要求都值得问一句「这是配合需求还是设计默认？」。

## 危险特征三件套

### 1. 薄壁（壁厚 < 1.5mm）

- **为什么难**：切削力与装夹力都会让薄壁变形；精铣时到位，后续工序（氧化、运输）还可能翘；
- **怎么处理**：T651 消应力板料、两面轮流对称粗铣、精铣小切深轻夹具；
- **报价前必问**：平面度/平面要求按氧化前还是氧化后验收？

### 2. 深孔（深径比 > 3:1）

- **为什么难**：排屑困难、刀具刚性不足，孔易偏、刀易断；深径比 > 5:1 要慎接；
- **怎么处理**：啄钻（钻一点退一点排屑）＋内冷＋铰孔修正；
- **报价前必问**：孔径公差多少？通孔还是盲孔？孔口有无毛刺要求？

### 3. 深腔（深而窄的型腔）

- **为什么难**：刀具伸入受限、排屑差、让刀（刀具受力偏移）导致侧壁不直；
- **怎么处理**：分段铣、加长刃刀具但降参数；
- **报价前必问**：腔底与侧壁的拐角半径多大？（R 越小＝刀越细＝效率越低＝越贵）

## 表面处理族谱

| 处理 | 原理一句话 | 外观/效果 | 成本 | 对尺寸的影响 |
|---|---|---|---|---|
| 阳极氧化 Type II | 电化学生成氧化膜并染色 | 哑光/亮面，可染多色 | 低-中 | 每表面净增约膜厚一半（膜 5-18μm） |
| 阳极氧化 Type III（硬质） | 厚膜硬氧化 | 灰黑，耐磨耐蚀 | 高 | 膜厚 13μm+，尺寸影响明显 |
| 喷砂（bead blast） | 喷射微珠打出均匀哑光 | 均匀磨砂质感，可盖细刀纹 | 低 | 影响极小 |
| 电镀（镀镍/铬） | 电沉积金属层 | 金属亮面 | 中 | 镀层厚度计入尺寸 |
| 镭雕 | 激光刻蚀 logo/文字 | 永久标识 | 低（按面积/数量） | 无 |
| 发黑（钢件） | 化学氧化膜 | 黑色防锈 | 低 | 极小 |

**两个常被忽略的点**：①阳极氧化染色对**基材状态敏感**——不同批次/不同厂的料，染出色可能有差异，严格对色要留色差余量或签色板；②密封面、配合面通常要**遮蔽（mask）**不氧化——多一道工序，是合法加价点。

## 把「做不了」变成「可以这样做」

工厂说「做不了」时，往往不是真做不了，而是「按现在的设计做不划算」。你的动作是**追问三层**：

1. 哪个特征卡住了？（壁厚？孔深？拐角 R？）
2. 设计上能不能让一步？（加大 R、减小孔深、放松非关键公差）
3. 带着让步方案回客户确认，再回厂重新报价。

这一套动作就是 DFM（可制造性反馈）的本质——你不需要自己懂工艺，但必须懂**工艺如何影响钱和交期**。

## 自测

1. ±0.02mm 和 ±0.05mm 之间的成本差异是「均匀上升」还是「跳档」？为什么？
2. 一个件上既有深孔又有薄壁，报价前你要问厂哪三个问题？
3. 客户要求氧化后底面平面度 0.02mm 且底面是密封面——你要建议什么工艺安排？
4. 「遮蔽氧化」什么时候需要？为什么它是合法加价点？
