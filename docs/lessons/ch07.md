# 第 7 章 市场与证据

!!! note "本章解决什么问题"
    「感觉某某市场不错」不能作为投入理由。这一章教你用公开证据选择和验证目标市场：海关统计数据、海运提单记录、社群与众筹平台信号——让每个市场决策都有数可依。

## 三套公开证据

| 证据源 | 能回答什么 | 怎么获取 | 局限（必读） |
|---|---|---|---|
| 海关统计数据 | 一个国家/地区「某类商品」的进出口总量与流向（宏观） | 各国海关公开平台、UN Comtrade（免费） | **宽税号≠你的产品**：税号按材料+用途分类，不存在「CNC 加工件」编码；只能做区域对比，不能当市场规模 |
| 海运提单记录 | 哪些公司在进口这类货（公司级线索） | 部分国家提单公开可查（如美国） | 只覆盖海运；数据有滞后；公司名≠你的目标买家 |
| 社群与众筹平台 | 产品级需求信号：什么设计正在被支持、什么话题活跃 | Kickstarter/Indiegogo、Reddit、行业论坛 | 信号碎片化，需要长期泡；热度≠订单 |

**用法**：三套证据拼起来——海关数据告诉你「哪个国家在进口」，提单告诉你「哪些公司在进口」，社群告诉你「哪些产品方向在升温」。任何单一证据都不足以下结论。

## 目标市场选择的常见逻辑

1. **购买力**：发达市场单价高（为响应、语言、低 MOQ 付溢价），竞争也激烈；
2. **本地制造业空心化**：本地机加房越少越贵，外包需求越真实；
3. **关税与贸易政策**：高关税市场（对华额外加税的品类）会吃掉利润，选市场前必查；
4. **语言与时区**：英语市场沟通成本最低；时区接近的市场（如东亚）响应体验好。

## 市场决策表（模板）

| 判断项 | 证据 | 结论 |
|---|---|---|
| 有没有进口需求？ | 海关数据：该类目目的国排名与金额 | 有/无/存疑 |
| 需求集中在哪些公司？ | 提单检索：进口商名单 | 列出 Top 名单 |
| 产品方向有没有热度？ | 社群/众筹：同类项目与讨论 | 强/弱 |
| 关税环境？ | 官方税率查询 | 友好/有税/高危 |
| 我够得到决策人吗？ | 渠道盘点（见第 8 章） | 可触达/触达不了 |

**投/不投的门槛**：前四行至少三行「有/强/友好」，且第五行「可触达」——否则放着，先做够得着的市场。

## 三个常见误读

1. **把海关大数当市场规模**：宽税号里混着大量非 CNC 品类，只能做「谁多谁少」的相对比较；
2. **把社媒热度当订单**：点赞不是采购，众筹支持者不是 B2B 买家；
3. **把单一买家反馈当市场结论**：一个客户说不需要，不代表市场不存在——样本要到 10+ 才有讨论价值。

## 自测

1. 为什么不能用海关税号数据直接回答「CNC 加工市场有多大」？
2. 三套证据分别解决「哪一层」的问题？
3. 一个市场海关数据排名靠前，但提单里找不到目标公司——你怎么解读？
4. 写出你的市场决策表五行的判断项。
