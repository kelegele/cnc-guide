# 第 10 章 成本与报价

!!! note "本章解决什么问题"
    报价是外贸服务商的核心技能：报高了丢单，报低了亏本。这一章教你完整的报价方法——从向工厂询价、核算成本，到制作一版专业的分项报价单。

!!! abstract "本章的三条线"
    - **货物流**：成本五件套逐项对应货物的一个环节——材料（起点）、机时（加工）、表面处理（外协）、检验（把关）、运费（末端）；
    - **资金流**：报价单是资金流的核心单据——口径归一（含税/含表面处理/数量档）是单据纪律；
    - **单据流**：数量档位决定货物流的批量形态——批量越大，Setup 摊得越薄。

## 询价方法：同表多厂，口径归一

工厂报价最大的陷阱不是「贵」，是「口径不一」——同样说「25 元一件」，含不含税、含不含表面处理、按哪个数量档，价格天差地别。方法：

1. **统一询价件**：选一个代表性零件（真实或示意），图纸/示意图＋四要素（材料、数量、表面处理、公差）写全，发给多家工厂；
2. **口径归一**：每份回复都追问三件事——含税吗？含表面处理吗？按什么数量档？；
3. **多厂交叉**：至少三家同口径报价，价格分布立刻真实——异常低（可能有诈）与异常高（没诚意）都现形；
4. **留档**：报价入台账（工厂/日期/口径/价格），这是你的成本底账第一行。

## 成本构成五件套

| 构成 | 内容 | 谁决定 |
|---|---|---|
| 材料 | 坯料价＋利用率损耗 | 材料行情＋零件尺寸 |
| 机时 | 机床时间×机时费 | 零件复杂度＋精度档＋批量 |
| 表面处理 | 氧化/喷砂/电镀等（常外协） | 处理种类＋数量（氧化按炉摊） |
| 检验 | 全检/抽检的人工与设备 | 公差严不严、要不要 CMM |
| 物流 | 快递/专线/海运＋偏远附加费 | 目的地＋重量＋条款 |

## 加价策略

- 行业常见以**工厂成本 ×1.15~1.30 起谈**，留出议价空间；报价必须覆盖你的隐性工作（沟通、验货、物流协调、风险）；
- **新客户**报总价（简单、专业感够）；**专业客户**用分项报价（材料/加工/表面处理/运费分列）建立信任；
- 数量分档报价（如 5/50/500 三档）——既显专业，又锁住复购的价格预期。

## 价格敏感性三规律

1. **公差跳档**（见[第 4 章](ch04.md)）：±0.05→±0.02 整件常见 +10%~30%，真实数字问厂；
2. **表面处理按数量摊**：氧化按炉收费——5 件摊一炉很贵，500 件摊一炉几乎白送；
3. **数量档位摊薄 Setup**：打样单价高是常态，报价单写清「含 Setup 费」避免客户误解。

## 报价单八要素

1. 公司/品牌抬头与联系方式（用品牌名，不写工厂名）；
2. 零件描述＋图纸版本号（per Rev X）；
3. 材料与状态（6061-T6）；
4. 数量档位与单价（或分项明细）；
5. 表面处理说明；
6. 贸易条款（DAP 城市名 / DDU 等，见[第 11 章](ch11.md)）＋运费；
7. 交期（工作日口径＋运输时间分列）；
8. **报价有效期**（通常 15-30 天）与付款条款。

**报价后的跟进**：发出后 3-5 天跟进一次；报价过期前主动刷新——很多订单死于「客户回头找不到那张报价单」。

## 自测

1. 「口径归一」要追问哪三件事？不做会发生什么？
2. 成本五件套里，哪两项对小批量单价影响最大？
3. 为什么数量分档报价既显专业又锁住复购？
4. 报价单为什么必须写图纸版本号和有效期？
