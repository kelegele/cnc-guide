## 议价：让步要交换

客户说 "Your price is too high"，新手最容易犯的错是**立刻降价**——降价不换条件，等于告诉客户「刚才虚报了」。正确动作：

1. **先问锚点**："May I know your target price?"——目标价合理就按目标价谈，不合理才知道差距多大；
2. **让步要交换**：降价必须换条件——加数量（"at 500pcs I can do X"）、放宽公差、调整表面处理、延长交期；
3. **非价格让步**：送样品、免打样费、加急排产——有时比降价便宜且客户感知更强；
4. **有底线**：低于成本＋隐性工作的价格，宁可不接——第一单亏本换来的客户往往是最难缠的客户。

## 交期：时间链与缓冲

一个订单的真实时间链＝工厂排产等待＋加工＋表面处理（外协往返）＋检验＋包装＋运输。**最容易延误的环节**：表面处理外协往返、临时插单、材料采购。

承诺原则：

- 交期写**工作日**并分列（加工 X 工作日＋运输 Y 天），不含周末与节假日；
- 在工厂报的交期上加 20%-30% 缓冲再承诺客户——宁可提前，不要延误；
- 延误征兆一出现就主动告知客户＋给新日期＋给补救——坏消息早说是售后信任的全部秘密。

## PI（形式发票）八要素

PI（Proforma Invoice）＝下单依据文件，双方签字（或邮件确认）后生效：

1. 双方信息（你的品牌抬头＋客户信息）；
2. 零件描述＋**图纸版本号**（per Rev X）；
3. 材料、表面处理、数量；
4. 单价与总金额（币种）；
5. 贸易条款（DAP 目的地）与运输方式；
6. 付款条款（30% 定金、70% 出货前）；
7. 交期（工作日口径）；
8. 验收标准（按签样/按图纸公差）＋争议解决方式。

## 定金与尾款

常见结构 **30% 定金下单＋70% 出货前付清**：

- 定金覆盖你的工厂定金与备料成本，客户弃单时不至于亏损；
- 尾款未到不发货——没有任何例外，"老客户"也要守（可以加快放货，不能免付款）；
- 样品费：小额可 PayPal（注意拒付风险），可约定「量产时抵扣」降低客户抵触。

## 下单前确认清单

下单/开工前逐项打勾，避免 90% 的扯皮：

- [ ] 图纸版本号确认（per Rev X）；
- [ ] 材料与状态（6061-T6）；
- [ ] 表面处理（颜色/类型/遮蔽要求）；
- [ ] 关键公差与验收基准（签样 or 图纸公差）；
- [ ] 数量与分档；
- [ ] 贸易条款、运费与目的地邮编（偏远核查）；
- [ ] 交期（工作日）；
- [ ] 付款条款与定金到账。

## 自测

1. 客户砍价 20%，你的第一个动作是什么？为什么不是降价？
2. 交期承诺为什么要在工厂交期上再加缓冲？哪些环节最容易延误？
3. PI 八要素里，漏掉「图纸版本号」和「验收标准」各会发生什么？
4. 「两端错位」的付款设计在 PI 里对应哪两条条款？
