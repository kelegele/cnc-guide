# 第 13 章 打样与量产

!!! note "本章解决什么问题"
    客户付款下单后的「黑盒期」最考验信任：工厂在做什么、进度正常吗、客户在催怎么办。这一章讲打样与量产两个阶段的管理动作——让每一单都在你的掌控里。

## 打样：用样品锁定一切

打样（prototyping）的目的不是「给客户看个大概」，而是**把口头和图纸变成实物基准**：

1. **打样报价**：样品费单独报（打样成本高是 Setup 摊不薄），可约定量产抵扣；
2. **寄样**：寄给客户前**自己先验收一遍**（尺寸、外观、氧化色）——把问题留在你手里，别寄给客户；
3. **签样（approved sample）**：客户书面确认样品合格——这份签样是后续所有品质争议的**裁定基准**；
4. **图纸封版**：签样后标注「按 Rev X + 签样生产」，任何改动走变更流程。

## 量产管理：三个检查点

| 检查点 | 动作 | 防什么 |
|---|---|---|
| 排产确认 | 书面确认排产日期与交期 | 工厂「忙忘了」 |
| 过程节点 | 加工完成时抽看（照片/首件尺寸） | 批量性错误（一张程序错=500 件全错） |
| 出货前验收 | 尺寸抽检＋外观检查＋包装拍照 | 病件出门、运输损伤扯皮 |

**原则**：问题必须死在你手里——出货前发现是「你的专业」，到客户手里发现是「你的事故」。

## 进度沟通：主动汇报，别被催

- **节奏模板**：排产确认时发一次；加工过半发一次（附照片）；出货前发一次（附验货照片）；发货后发追踪号；
- **三段式汇报**：现在做到哪 → 下一步是什么 → 预计什么时间到哪个节点；
- **坏消息早说**：延误征兆一出现就告知＋新日期＋补救方案——客户对延误的容忍度远高于对「被瞒到最后」的容忍度。

## 变更管理：改单的规矩

客户中途改图纸/改数量/改表面处理时的铁律：

1. **先报价再改单**：任何变更都可能改变成本与交期，重新确认后才执行；
2. **书面留痕**：变更以邮件确认为准，不接口头改单；
3. **已产部分怎么算**：已加工件是否报废、费用谁担——提前说清，不要事后扯。

## 自测

2. 量产的三个检查点分别防什么？
3. 进度汇报的三段式是什么？为什么坏消息要早说？
