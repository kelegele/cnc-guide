# 第 15 章 售后与复购

!!! note "本章解决什么问题"
    一单的结束是下一单的开始。这一章讲交付之后的经营：客诉怎么处理才不丢客户、索赔与让步接收怎么谈、怎么把一次性买家变成年年复购的长期客户。

!!! abstract "本章的三流"
    - **货物流**：复购订单的货物流，因为历史记录（单据流）完整而更快更顺；
    - **资金流**：索赔赔偿是资金流的回流——谈得好坏直接影响利润；
    - **单据流**：复盘更新检查清单是单据流的知识沉淀；关系是三流的润滑剂——客诉处理好坏，决定客户愿不愿意让三流再跑一遍。

## 客诉处理四步闭环

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 受理 | 快速回应：收到、重视、正在查 | 回应要快、结论可以慢；不辩解不甩锅 |
| 2 调查 | 查图纸/签样/检测报告/工序记录 | 用证据说话，不凭感觉认责 |
| 3 方案 | 返工/重做/折扣/让步接收，给客户选项 | 责任在我方→主动担；双方有争议→证据协商 |
| 4 复盘 | 归档问题→更新检查清单→不再重犯 | 每个客诉都是流程改进的免费咨询 |

英文回复模板见[热身课坑三](lesson-0.md)与[英语分册场景 4](en04.md)。

## 索赔与让步接收

- **责任在我方**：主动承担返工/重做费用＋运输费——但赔偿范围以「货值」为限，谈判时说清间接损失（客户的生产损失）不在承接范围；
- **责任有争议**：引入第三方检测裁定（费用协商），按裁定结果执行；
- **让步接收（concession）**：客户书面同意「当前状态可接收」并换取折扣——**必须是客户书面确认**，口头让步=无限后患；
- **底线**：安全问题（结构失效、食品接触）零容忍，宁可全赔不推让步。

## 复盘机制

每单结束（尤其是出过问题的单）做十分钟复盘：

1. 什么问题？→ 2. 根本原因是什么（不是谁的错，是流程哪一环缺失）？→ 3. 检查清单里加一条什么规则？

例：客诉「氧化色差」→ 根因「没签色板」→ 清单新增「染色件必须签色板」。三个月后，你的清单就是别人抄不走的经验库。

## 客户分层与复购经营

| 层级 | 特征 | 动作 |
|---|---|---|
| A 复购客户 | 半年内 ≥2 单 | 优先响应、价格倾斜、新品主动推荐 |
| B 潜力客户 | 打样过/深聊过 | 节点跟进（新产能、新工艺告知） |
| C 沉睡客户 | 半年以上无动静 | 节日问候＋轻触达，唤醒即升级 |

**复购触发设计**：报价有效期到期前主动刷新；批量用完前主动提醒（"你的 500pcs 应该快用完了"）；新工艺样片主动分享——复购不是等来的，是设计出来的。

## 自测

1. 客诉四步闭环里，为什么「回应要快、结论可以慢」？
2. 让步接收为什么必须书面确认？什么情况下绝对不让步？
3. 复盘的产出物是什么？举一个「问题→清单规则」的例子。
4. A/B/C 三层客户各自的维护动作是什么？
