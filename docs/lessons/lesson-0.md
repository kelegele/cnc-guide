# 绪论 · 三个最常见的坑

CNC 加工外贸里，新手最容易翻车的地方出奇地一致：**薄壁件报废、公差涨价、客诉刀纹**。这堂绪论课用三个场景把这三个坑各走一遍——不求你记住全部细节，只求你建立两个直觉：**这个行业的坑在细节里；每个坑都有「报价前必问」的问题**。

## 坑一：薄壁件的平面度，为什么铣好了还会报废

**场景**：客户发来一张图纸——6061-T6 铝合金壳体，最薄壁厚 1.2mm，底面平面度要求 0.02mm（约为三分之一根头发丝），表面黑色阳极氧化。新手最容易答「那个 5:1 的深孔难钻」。

**答错了。深孔只是「贵」，平面度才是「险」**：

- 深孔 3mm×15mm（深径比 5:1，即深度是直径的 5 倍）确实麻烦：必须啄钻（钻头钻一点就退出来排屑再钻，像啄米，防止排屑堵死断刀），孔径易超差还得铰孔修正——但它花的是钱，不直接导致报废；
- 平面度 0.02 则是报废源头：精铣时能做到 → 工件进阳极氧化槽 → **1.2mm 的薄壁在槽内热变形，出槽常翘** → 平面度超差，整件报废。

**报价前必问**：「平面度按氧化前还是氧化后验收？」——图纸不注明时，工厂和氧化厂对此理解不同，这是纠纷高发点。

**处理六步**（给你留个印象，细节在「听懂工艺」阶段展开）：T651 消应力板料 → 两面轮流对称粗铣去应力 → 精铣小切深、轻夹具 → 与客户确认验收基准 → 与氧化厂沟通装挂方式 → 深孔啄钻＋铰孔＋去毛刺。

**顺带一个冷知识**：深小孔内壁的氧化膜会长不匀、偏薄发白。客户若要求孔内也均匀发黑，要提前说明工艺限制——这类「客户不知道的工艺限制」，正是你的价值所在。

## 坑二：公差每紧一档，成本跳一档

**场景**：同一款零件，客户发来两个版本——A 版关键尺寸公差 ±0.05mm，B 版 ±0.02mm，其他完全一样，问你能便宜多少或贵多少。

**先别急着报价，先反问**：「这两个尺寸的 ±0.02 是配合需求（要装轴承、密封件），还是设计默认值？」——很多客户把公差写紧只是习惯，**帮客户把不必要的 ±0.02 放宽到 ±0.05，替他省钱，是这行最高级的销售动作**。

**成本机制**（为什么紧公差贵）：

| 公差带 | 加工 reality | 成本含义 |
|---|---|---|
| ±0.1 | 普通加工顺手就到 | 几乎不加价 |
| ±0.05 | 普通精铣可达，多数厂的常规口径 | 基准价 |
| ±0.02 | 慢走刀、小切深＋每件全检＋报废率上升 | 受影响特征加价 15%~50%，整件约 +5%~30% |
| ±0.01 | 要上磨床等精加工工艺 | 接近翻倍 |

两条行业规律值得记住：**这条曲线是非线性的**（每紧一档不是均匀加价，而是跳档）；**紧公差不一定要换设备**（±0.02 在常见数控设备能力圈内，贵的只是工时、检测和风险缓冲）。

**那到底贵多少钱？** 正确答案不是背一个百分比，而是**问厂**：把 A/B 两个版本原样发给工厂，各要一个批量价，差价自然浮出。报价永远是「工厂说了算」，你的价值是把问题问对。

## 坑三：客户说「表面有刀纹」，怎么回

**场景**：客户发邮件——

> The surface finish doesn't meet our spec. We see some tool marks on the bottom surface. Can you check?
> （表面光洁度没达到我们的规格，底面有一些刀纹，你们能核查一下吗？）

**第一步永远是查图纸和签样**（approved sample＝客户此前确认过的样品，是纠纷的裁定基准），然后按三种情况处理：

1. 图纸标注了 Ra 值（表面粗糙度，数字越小越光）且实测超差 → **客观不合格，认**，返工或重做；
2. 图纸没标 Ra → **引导客户确认期望值**，同时问清用途：这面是密封/贴合面，还是纯外观面？
3. 黑色染色件常见「氧化前还行、氧化后刀纹变明显」——染色会放大视觉缺陷，属于可协商的外观问题。

**为什么「是不是密封面」是关键问题**：平面度要求 0.02 的底面，大概率是压垫圈的密封面（产品防水防尘就靠它）。刀纹是一排排小凹沟——**横穿密封线的刀纹会连成「从里通到外」的微通道，压力一推就漏**；密封面一漏，客户面对的是整机进水报废、退货索赔。所以密封面不合格必须返工，外观面则可以协商用喷砂盖纹。

**回复的四步结构**（可直接套用）：谢谢照片 → 我们在查 → 反问两个关键问题（Ra 值？密封面还是外观面？）→ 承诺何时给结论。完整英文模板见[9.2 询盘英语十句](l5-01.md)。

## 术语卡 · 本课 16 词

| 英文 | 中文 | 备注 |
|---|---|---|
| spec (specification) | 规格 | meet spec 达标 / out of spec 超差 |
| tolerance | 公差 | ±0.05/±0.02 |
| surface finish | 表面光洁度 | ⚠️ 歧义词，也可指表面处理（氧化喷砂） |
| Ra (surface roughness) | 表面粗糙度 | 越小越光 |
| tool marks | 刀纹 | 机加行业黑话 |
| flatness | 平面度 | 面平不平 |
| callout | 图纸标注 | callout on drawing 图上标的要求 |
| revision | 图纸版本 | rev A/B |
| approved sample | 签样 | 纠纷裁定基准 |
| rework | 返工 | scrap＝报废 |
| sealing surface | 密封面 | 功能性，配密封圈防漏 |

## 自测

1. 一个薄壁件精铣时平面度达标，为什么氧化后可能报废？
2. 客户问 ±0.02 比 ±0.05 贵多少，你的第一步动作是什么？（提示：不是报价）
3. 收到刀纹客诉，回复前必须先查哪两样东西？
4. 「密封面必须返工、外观面可协商」的分界依据是什么？

四题都能答上来，按学习地图继续；答不上来就回来重读对应小节——绪论课的目标就是让你带着这三个直觉进入正课。
